# Legacy browsers (first-gen iPad mini, iOS 9.3.5 / Safari 9)

`npm run build` now emits two bundles. Modern browsers load the normal ES module
bundle; browsers without `type="module"` support (Safari 9, iOS 9) load a
SystemJS + core-js `nomodule` bundle instead. `bridge/` embeds all of `dist/`,
so no bridge changes are needed — open `http://<pc-ip>:<port>/` on the iPad.

| Gap in Safari 9 | Handled by |
| --- | --- |
| ES2016+ syntax, `Object.entries`, `Promise`, … | `@vitejs/plugin-legacy` (Babel + core-js), targets `safari >= 9` |
| `ResizeObserver`, `Path2D`, prefixed `webkitAudioContext` | `src/legacy/shims.ts` |
| CSS Grid (< 10.1) | flexbox/float fallbacks in `src/legacy/legacy.css` (`@supports not (display: grid)`) |
| flexbox `gap` (< 14.1) | `<html class="no-flex-gap">` set at runtime; CSS rules generated by `tools/postcss-flex-gap.mjs`; inline `style={{ gap }}` rewritten by `src/legacy/jsx-runtime.ts` |
| `inset`, vendor prefixes | `build.cssTarget: 'safari9'` |

Known limits on the iPad mini 1: no Pointer Events (drag-to-reorder in settings
panels, which uses dnd-kit `PointerSensor`, won't work); Google Fonts need
internet access from the iPad (otherwise system fonts are used); the race
engineer voice needs a tap to unlock audio and has not been verified on device.
The flex-gap/grid fallbacks are approximations, so expect small spacing
differences versus a modern browser.
